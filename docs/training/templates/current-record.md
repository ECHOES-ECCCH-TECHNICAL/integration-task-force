# Current record section

The curator inserts the section below at the top of the existing TIU issue body, above the submitted Candidate Card. Keep the Card intact and update this summary after each decision. Use comments for dated assessments and decision history. The issue is the authoritative record; Project fields are a manually maintained index of the current decision.

Replace every bracketed prompt. Use `Unassigned`, `Pending — [owner and next step]`, or `Not applicable — [reason]` where appropriate. A planned location is not an actual publication or discovery link. An EITF issue number identifies the TIU; it does not replace the hosted resource's persistent identifier.
