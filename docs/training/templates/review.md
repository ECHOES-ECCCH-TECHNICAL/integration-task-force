# Review and maintenance comment

Copy this template onto the existing TIU issue for a review, delivery report, update or retirement decision. Reuse the same issue across deliveries, translations and versions unless they need independent ownership and assessment. Keep active TIUs open even when their technical Integration Unit children are complete.

Replace bracketed prompts and use `Not applicable — [reason]` for irrelevant sections. Keep indicators proportionate: record aggregate findings and evidence, not learner-level records. WP4 may contribute community feedback; WP9 may contribute evaluation or pilot evidence. This template implements [D5.2, workflow steps 6–8 and Annex 4](https://zenodo.org/records/20442259).

Default cadence is an annual relevance check for Level 1, every two quarterly EITF Integration cycles for Level 2, and every cycle plus relevant component changes for Level 3. These are local defaults; record any WP5-agreed adjustment. Level 1 checks are basic relevance/access checks and do not use an integration cycle or full curricular review.
