# Validation comment

Copy the comment below onto the existing training Resource issue when developed Level 2–3 material is ready for assessment. WP5 Task Leads lead the assessment, with relevant component teams contributing technical alignment evidence when required. Basic Level 1 listing uses the [intake template](intake.md) instead.

Replace every bracketed prompt. Replace `Pending` with `Met`, `Minor revision`, `Not met`, or `Not applicable`, and provide evidence. Explain every non-applicable criterion; missing evidence is not “not applicable”. The criteria and four outcome choices preserve [D5.2, Annex 3](https://zenodo.org/records/20442259). Its “learning objectives” correspond to the Candidate Card's learning outcomes.
