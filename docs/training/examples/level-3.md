## 3. Learners

### Target audiences

Heritage practitioners assessing whether OCRA is relevant to their working context, and facilitators introducing the component within a broader ECHOES learning pathway.

### Intended learner proficiency

Introductory

### Prerequisites and assumed knowledge

Familiarity with one heritage project or collection-management scenario. The draft introduces component terminology and requires no prior OCRA use. Actual component-specific prerequisites must be agreed with the component team during development.

### Estimated learner effort

2 hours: a 45-minute guided introduction, a 45-minute scenario exercise, and a 30-minute facilitated discussion or self-review.

## 4. Learning purpose

### Concrete use case or identified need

A practitioner encountering OCRA through ECHOES needs a clear introduction that connects the component's verified purpose to a realistic heritage scenario. The learning resource should explain prerequisites and limitations and show where authoritative component documentation can be found as the service evolves.

### Learning goals

Support an informed first encounter with OCRA within an ECHOES learning pathway. The module uses a guided scenario, terminology notes and component-team-reviewed examples to help practitioners understand the component's intended use and assess its relevance. It also teaches learners how to recognise the version covered by a tutorial and find current documentation. Full integration is proposed because the material would be embedded in a maintained curriculum and revised alongside relevant component changes, not because the introductory audience needs advanced training.

### Learning outcomes

- Explain OCRA's purpose using terminology confirmed by the component team.
- Compare a learner's heritage scenario with the verified scope and prerequisites described in the module.
- Identify the component version covered by a training example and locate its authoritative documentation.
- State where to seek clarification when a scenario falls outside the module's reviewed scope.
